# Flutter 101

A small, human-written Flutter learning project based on the provided Flutter 101 course materials.

## Topics covered

- Flutter fundamentals
- Cross-platform development
- Dart basics
- StatelessWidget and StatefulWidget
- `build()` and `setState()`
- Widget tree and state lifecycle concepts
- `Scaffold`, `Text`, `Icon`, `Container`
- `Row`, `Column`, `Stack`, `Card`
- `ListView`, `GridView`
- `GestureDetector`
- Dart functions, loops, null safety, classes, inheritance, mixins, async/await

## Run

```bash
flutter pub get
flutter run
```

## Project structure

```text
lib/
  main.dart
pubspec.yaml
README.md
```

The app is intentionally kept simple so the widgets and Dart concepts from the lessons are easy to inspect and modify.
